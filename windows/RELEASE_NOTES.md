# Splat for Windows (early preview)

- Initial Windows desktop shell using Tauri 2 and Microsoft Edge WebView2.
- Reuses Splat's Rust Markdown rendering, file-format preservation, safe Git reader and rich HTML import crates.
- Includes split live preview, source editing, file open/save, outline navigation and HTML export.

This is an early preview. It does not yet provide full parity with the macOS application. See `windows/README.md` for known gaps.
