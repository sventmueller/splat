# Splat for Windows (early port)

This directory contains a Windows desktop application built with Tauri 2 and WebView2. It is deliberately isolated from the upstream macOS application so the AppKit implementation, signing flow and existing release process remain untouched.

The Windows shell reuses the platform-independent Rust crates from the repository:

- `splat-markdown` for Splat's own Markdown model and safe HTML renderer.
- `splat-file-state` for BOM, line-ending and UTF-8 / BOM-marked UTF-16 preservation.
- `splat-git` for reading a file's committed version and calculating changed lines without starting Git or executing repository hooks.
- `splat-import` for converting rich HTML clipboard content to Markdown.
- `splat-preview` and `splat-notes` remain the next core libraries to integrate for two-way preview mapping and folder navigation; they are intentionally not pulled into this first binary yet.

## Current Windows MVP

- Native Windows window powered by Tauri 2 / Microsoft Edge WebView2.
- Split source and live preview, plus source-only and preview-only layouts.
- Live HTML generated by Splat's platform-independent renderer. The renderer's HTML sanitization and content-security policy are retained; remote and `file://` images are blocked in the live preview until an explicit image-consent flow is implemented.
- Open and save `.md`, `.markdown`, `.mdown` and `.mkd` files.
- Preserve UTF-8 BOM, UTF-16 LE/BE BOM and CRLF when saving an opened document.
- Basic Markdown source highlighting, outline navigation, formatting shortcuts and HTML export.
- Git changes against the last commit, using Splat's safe in-process Git reader.
- Local-first: no telemetry or document upload is added by this port.

## Known gaps before calling this feature-complete

This is an initial port, not a claim of feature parity with the macOS app. The preview is read-only in this first iteration. Mermaid / Graphviz / PlantUML and MathJax figure rendering, two-way preview editing, folder-wide note search and rename/link rewriting, full Word/PDF exports, application menus, file associations, crash recovery, auto-save, update checks and code signing still need platform-specific integration and tests. The current file size guard is 50 MiB.

## Build on Windows 10 / 11 (x64)

Prerequisites:

- Rust stable with the `x86_64-pc-windows-msvc` host toolchain.
- Microsoft C++ Build Tools with **Desktop development with C++**.
- Microsoft Edge WebView2 Runtime. It is already present on Windows 10 version 1803+ and Windows 11; the NSIS installer uses Tauri's WebView2 bootstrapper for systems that need it.

From the repository root in PowerShell:

```powershell
cargo install tauri-cli --version '^2' --locked
cd windows/src-tauri
cargo tauri dev
```

Build the NSIS setup executable:

```powershell
cargo tauri build --bundles nsis
```

The installer is written under `windows/src-tauri/target/release/bundle/nsis/`.

## Release automation

`.github/workflows/windows-release.yml` builds the x64 NSIS installer on GitHub-hosted Windows runners. Pushes to `main` or `windows-port` and manual workflow dispatch produce a downloadable Actions artifact. Pushing a tag such as `windows-v0.1.0` also creates a GitHub Release and attaches the setup executable.

The first Windows releases are unsigned. Windows SmartScreen may show an unknown-publisher warning until a code-signing certificate is configured. Do not disable Defender or SmartScreen to install an unsigned build unless you have independently reviewed the artifact.
