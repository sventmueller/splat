# Security policy

## Report a vulnerability

Please report it [privately on GitHub](https://github.com/sventmueller/splat/security/advisories/new), not in an issue
or a discussion: both are public. Keep it private until a fix is out.

Name the Splat version and the macOS version and describe how to reproduce it. Attach a small sample document if one
triggers it.

## What counts

Splat treats every document as untrusted. Anything that breaks a promise under
[Privacy and security](README.md#privacy-and-security) is a vulnerability, for example a document that runs code,
reaches the network without your permission or gets out of a decoder's sandbox.

## Supported versions

Security fixes go into the latest release only.
